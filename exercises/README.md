# Практические упражнения в IDE

Отдельные упражнения по Java, Git и сборке помогают проверить приёмы разработки на небольших примерах. Они сгруппированы по спринтам; полноценные приложения и работы для ревью находятся в `projects/`.

| Спринт | Упражнения |
| --- | --- |
| 1 | [JUnit 5: калькулятор и жизненный цикл тестов](sprint01/junit5/README.md) |
| 2 | [Каталог упражнений](sprint02/README.md): история Git, Maven-отчёт, Gradle-преобразование файлов |
| 3 | [Каталог упражнений](sprint03/README.md): Spring AOP, WAR и JDBC |
| 4 | [Каталог упражнений](sprint04/README.md): Spring Boot, Maven/Gradle и Actuator |
| 5 | [Каталог упражнений](sprint05/README.md): Spring Data JDBC, MySQL и Liquibase |
| 6 | [Каталог упражнений](sprint06/README.md): Java Flow, R2DBC, MySQL и HTML-приложение WebFlux |
| 7 | [Каталог упражнений](sprint07/README.md): OpenAPI, REST API автомастерской и Spring Data Redis |
| 8 | [Каталог упражнений](sprint08/README.md): OIDC login, Keycloak и защищённая пара WebFlux-сервисов |

У каждого решения свои исходники, версии инструментов, команды запуска и результаты проверки. Материалы оформлены как описание выполненной работы, без переноса теории и банка ответов тренажёра.
