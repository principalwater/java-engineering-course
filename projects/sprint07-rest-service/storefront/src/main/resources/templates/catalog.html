Управление каталогом

Загрузите товары одним JSON-файлом. SKU сохраняет идентичность товара при повторном импорте.

Коллекция мастерской

Восемь предметов для рабочего места: от клавиатуры до растения. Уже существующие SKU обновятся без дублирования.

Импорт из JSON

Формат файла и доступные иллюстрации

Цена указана в целых рублях. SKU состоит из латинских букв, цифр и дефисов. Файл применяется целиком: ошибочная строка отменяет импорт.

[
  {
    "sku": "my-keyboard",
    "title": "Моя клавиатура",
    "description": "Описание предмета",
    "image": "KEYBOARD",
    "price": 7900
  }
]

Иллюстрации: KEYBOARD, MONITOR, LAMP, NOTEBOOK, PLANT, CUP, HEADPHONES, DOCK.
