# Спринт 2 — инструменты разработки

## Цель

Проверить работу с историей Git и реализовать собственные плагины Maven и Gradle.

## Упражнения

| Работа | Решение | Проверка |
| --- | --- | --- |
| Индексирование, stash, bisect и объединение коммитов | [Git](git/README.md) | Воспроизводимые проверки индекса, файлов и истории |
| Генерация отчёта по результатам Surefire | [Maven-плагин](test-report-maven-plugin/README.md) | JUnit и вызов цели из проекта-потребителя |
| Преобразование файлов и подсчёт слов | [Gradle-плагин](file-transformer-gradle-plugin/README.md) | TestKit, проверка метаданных и отдельный consumer |

Для Java-примеров требуется JDK 21; версии сборщиков закреплены в wrappers. Git-практика запускается Python 3 и Git и работает со своими временными данными в `target/`.
