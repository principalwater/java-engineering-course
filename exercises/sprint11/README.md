# Спринт 11 — наблюдаемость

Три стенда проверяют разные сигналы работы приложения.

| Упражнение | Результат |
| --- | --- |
| [Трассировка HTTP-цепочки](tracing-chain/README.md) | Micrometer и Zipkin: шесть связанных spans, ошибка последнего вызова и изоляция контекста |
| [Мониторинг заказов](monitoring/README.md) | Actuator, Prometheus и Grafana: метрики, конечная нагрузка и письма FIRING/RESOLVED через Alertmanager |
| [Обработка кофейных логов](coffee-logging/README.md) | Filebeat, Kafka, Logstash, Elasticsearch и Kibana: фильтрация, индексация, повторная доставка и перенос пяти панелей |

Команды, ограничения и снимки результата находятся в описаниях стендов. Java 21 — общий baseline; версии библиотек и Docker-образов закреплены в каждом упражнении.
